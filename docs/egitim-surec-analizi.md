# Eğitim süreci — nereden geldik, şimdi neredeyiz

Kaynak kontrolü (2026): [IVAO ATC ratings](https://wiki.ivao.aero/home/training/main/rank_atc), [IVAO ADC briefing](https://wiki.ivao.aero/en/home/training/main/atc_briefing/ADC_Briefing), [SHGM eğitim süreci](https://web.shgm.gov.tr/tr/s/2113-a-egitim-sureci), ICAO Doc 9432 (Roger / Wilco / Affirm / Standby).

## 1. Nasıl ilerledik

| Sıra | Ne yaptık | Ne değil |
|---|---|---|
| 1 | Auth, kullanıcı, JWT, audit | — |
| 2 | Blog (yaz, incele, yayımla, medya) | Udemy kurs vitrini |

İki paralel yol:

```text
Kule ol  →  TWR gibi konuş, ADC’ye hazırlık, IVAO dinle
Pilot ol →  PIC gibi konuş, PP’ye hazırlık, IVAO uç
     ↓
Uçaklar  →  kokpit / sistem / alet (henüz yok)
```

## 2. Kule hattı (9 adım) — süreç

1. Kimdir → TWR, GND, DEL, separation  
2. Türkiye ATC → DHMİ, SHGM, OJT, unit rating  
3. IVAO merdiven → AS1–ADC (observer saati sayılmaz, 75/100, 60 gün AS3)  
4. Dinle RT → Roger ≠ onay, Affirm, Standby, Contact vs Monitor  
5. Konuş Ground → push and start  
6. Line up vs take-off → pist ihlali  
7. Senaryo iniş → cleared to land / go around  
8. Kalkış sırası → push → taxi → line up → take-off  
9. IVAO canlı → observer + SOP  

---

## 3. Pilot hattı (11 adım) — süreç

1. Kimdir → PIC, FO, PF, PM  
2. SHGM lisans → SPL, PPL (45 sa, Sınıf 2), CPL (200 sa, Sınıf 1), ATPL (1500 sa, 14 ders/75)  
   Türkiye **EASA ülkesi değil** (SHT-FCL benzer, otomatik EASA lisansı yok)  
3. IVAO → FS1–PP (pilot saati, 2 hafta kuralı)  
4–9. ATC ile konuş: ilk çağrı, pushback, taksi read-back, line up, kalkış, iniş  
10. MAYDAY / PAN PAN / squawk 7700-7600-7500  
11. IVAO circuit + uçuş planı

## 4. Rehberlerde eksikti, eklenenler

| Konu | Neden |
|---|---|
| Roger ≠ read-back | ICAO: Roger talimat tekrarı değildir |
| Affirm / Negative | "Yes/no" yasak; affirmative negative ile karışır |
| Contact vs Monitor | Biri konuş, biri sadece dinle |
| IVAO observer saati | ATC rating saatine sayılmaz |
| ADC 60 gün + 75/100 | IVAO resmi ADC briefing |
| SPL + Sınıf 1/2 | SHGM tablosu; PPL Class 2, CPL Class 1 |
| SHT-FCL ≠ EASA | Türkiye lisansı EASA tesciline binmez |
| 45 / 200 / 1500 saat | SHGM asgari tecrübe |
| Squawk 7700/7600/7500 | Acil / radyo arızası / korsanlık |
| Niner, Tree, Fife | ICAO rakam telaffuzu |

---

## 5. Bu henüz gerçek kokpit değil

Şu an **radyo + süreç + terim**. Kullanıcı kule/pilot gibi konuşmayı öğreniyor.

Kokpit (sonraki faz — uçaklar):

- PFD / ND / EICAS benzeri aletler  
- Trim, flap, gear, throttle  
- Checklist  
- Uçuş fazı: push → taxi → take-off → climb → approach → land  

O faz gelince sistem “konuşan eğitim”den “uçuran eğitim”e geçer.

---

## 6. Karar

Kule + pilot **süreç ve terim** katmanı kapanmaya hazır.  
Sıradaki iş: **uçaklar / kokpit**.
