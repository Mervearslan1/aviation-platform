# Aviation Platform — flight UI

Learner surface (cockpit) and a separate ops desk.

```powershell
cd frontend
npm install
npm run dev
```

Open http://localhost:5173  
Backend should be on http://127.0.0.1:8080 (`/api` is proxied).

- Flight: `/` `/tower` `/pilot` `/cockpit`
- Ops: `/ops`
- TR/EN and day/night are in the glareshield
